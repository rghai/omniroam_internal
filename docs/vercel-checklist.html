  • Use `https://omniroam.vercel.app` as the site URL.
  • Keep checkout in demo mode.
  • Keep founder test flow, Opn charges, supplier writes and transactional email off.

Protected Preview

  1. Turn on Vercel Deployment Protection.
  2. Use Opn test mode and the founder test flow.
  3. Add the Opn test public and secret keys.
  4. Enable test charges, not live charges.
  5. Add the Neon connections, hash secret and eSIM encryption key.
  6. Add eSIMAccess server credentials.
  7. Map only the founder plan `qa-th-0.1-7` to the current Thailand 100MB, seven-day supplier package.
  8. Keep the supplier cap at US$0.50.
  9. Enable supplier writes only after the package and price have been checked live.

Founder email

  • Use `Omniroam <onboarding@resend.dev>` for the canary.
  • Resend's testing sender can deliver only to the Resend account email.
  • The email has HTML and text parts and works without images.
  • The private recovery address is plain text so click tracking cannot wrap it.
  • A real customer sender waits for the next owned domain and its SPF, DKIM and DMARC setup.

Run and close the canary

  1. Redeploy Preview after settings change.
  2. Confirm the founder-only Thailand 100MB plan is visible.
  3. Top up only enough for one approved canary.
  4. Run payment, supplier order, email, recovery, QR, installation and usage checks.
  5. Replay the same request and confirm no duplicate charge, eSIM or email.
  6. Turn supplier writes off again immediately.

A future domain remains easy to change

The app has no hard dependency on the expired domain. A replacement changes the configured public URL, email sender, support links and Turnstile hostname list. The checkout and supplier flow do not change.
