One founder session

Configure the controlled test once, after the current implementation sprint.

This page names the settings without exposing their secret values. Add secret values directly in Vercel.

Customer product

SettingAction
Site URLUse the Vercel URL until goomniroam.com is connected.
Checkout modeUse Opn test mode for controlled testing.
Market and currencyDefault to Australia and AUD.
ConsentKeep the testing notice mode. Analytics and marketing stay off.
LogsUse warning level in production and more detail only in development.

Payments and eSIM

  • Add the Opn test public and secret keys as protected variables.
  • Enable test charges only. Do not add a live Opn key.
  • Reuse the existing reserved eSIM during this stage.
  • Add the reserved test order and plan identifiers as protected values.
  • Keep eSIMAccess supplier writes false.
  • Keep the experiment cap at US$0.50.
  • Add the eSIMAccess access and signing values as protected variables.

Database and protected data

  • Keep the pooled and direct Neon connections.
  • Add a new random security hash value of at least 32 bytes.
  • Add a new base64 eSIM encryption value representing exactly 32 random bytes.
  • Confirm the current migration before the controlled production test.

Email

  • Verify goomniroam.com in Resend.
  • Add SPF and DKIM, then a DMARC monitoring record.
  • Use an Omniroam orders sender and a monitored support reply address.
  • Disable transactional click tracking.
  • Enable transactional email only after sender and reply inbox checks pass.

Turnstile

  • Add the existing public site key and protected server secret.
  • Allow only the Vercel and goomniroam.com hostnames in production.
  • Enable enforcement after a production-host test.
  • Do not put Turnstile on checkout unless measured card-testing abuse justifies it.

Keep off

  • Google Analytics and Google Tag Manager
  • eSIMAccess supplier writes
  • Automatic refunds
  • Advertising tags
  • Internal staff dashboard access
  • Scheduled alert sweeps
  • Opn live charges

After configuration

  1. Redeploy once.
  2. Confirm GitHub release checks and Vercel deployment are green.
  3. Run one controlled test through payment, reserved eSIM retrieval, email, recovery and replay protection.
  4. Record the result in Notion and the founder dashboard.
Do not enable public live sales yet.

Verified webhooks, reconciliation, 3-D Secure recovery, fraud controls, legal details and staff operations still block launch.
