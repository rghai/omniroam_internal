Every release carries evidence.

Automated tests, browser checks, operational safeguards and founder feedback now form one regression gate.

Release gate

Automated

  • Lint
  • Node regression tests
  • Next.js production build
  • Copy style, consent, pricing and provider-boundary tests
  • Reusable brand-asset checks

Browser and visual

  • Desktop and 360 to 430-pixel phone view
  • No console error or error overlay
  • No horizontal overflow
  • All images load after scrolling
  • No character covers copy, controls or conditions

Payments and fulfilment

  • One payment creates no more than one order
  • Supplier writes match the approved mode
  • Refunds remain human-only
  • Test and live credentials stay separate

Privacy and operations

  • Consent defaults match the environment
  • Support and DSAR create durable references
  • Staff access remains separate and fails closed
  • No secret or customer data enters release evidence

Exceptions and approval

Release owner may log

A reversible presentation exception that does not affect accessibility, hide a limitation or touch money, fulfilment, privacy, law or security.

AM or KG must approve

Any conflict involving payment, pricing logic, supplier writes, refunds, customer data, consent, legal wording, authentication, security controls or production launch claims.

If a proposal conflicts with an earlier QA check, record the conflict, reason, added risk and supporting evidence before changing the rule.
