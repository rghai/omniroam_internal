# Public Omniroam briefing: agent rules

This repository and its GitHub Pages site are **public**. It is a dated, secret-free briefing/archive, **not** the authoritative founder operating dashboard.

## First read

- Private application source and canonical project operating guide: [rghai/omniroam](https://github.com/rghai/omniroam) (requires authorised access), `docs/PROJECT_OPERATING_SYSTEM.md`.
- Live operational controls: [restricted founder console](https://omniroam.vercel.app/internal/founder) (founder sign-in required).
- Founder decisions and tasks: private [Notion Codex](https://app.notion.com/p/3cb2665f0afb80a9a095c7c5a90de479).

## Edit rules

1. Every summary must declare a **date or release SHA**, distinguish confirmed historical evidence from current live status, and link to its owner/source. Static values must never be described as automatically live.
2. Do not mirror operational task lists, live release switches, current catalogue counts or founder decisions here. Link to the owner. Never create another parallel 'source of truth'.
3. No credentials, customer identities, eSIM activation/QR data, payment logs, internal order details, private financial values, secret environment variables or staff-only access links with tokens. `noindex` is **not** authentication.
4. No live application code, checkout, payment, fulfilment, staff access or deployment settings belong here.
5. Keep Australian English, humane editorial copy, no em dashes and the established Omniroam cream/navy/mint/coral/yellow look.
6. Use a reviewed branch/PR, maintain navigation and mobile readability, and verify affected static HTML/CSS. Do not overwrite unrelated snapshots or silently rewrite historical dates.
7. If a historical statement is superseded, **label** it, do not erase the record. If a claim cannot be verified, mark it unverified or remove only the claim.
